# Security policy

## Supported versions

Security fixes are prioritized for the current `main` branch and the latest
released 0.x version.

## Reporting a vulnerability

Please do **not** open a public issue for a suspected vulnerability. Use the
[private vulnerability-reporting flow on GitHub](https://github.com/phcodesage/pyrora/security/advisories/new)
and include a clear impact description, affected version or commit, a minimal
reproduction, and any proposed mitigation.

If the GitHub private-reporting option is unavailable, contact a repository
maintainer privately through GitHub and do not include exploit details in a
public issue. We aim to acknowledge reports within seven days and will
coordinate a fix and disclosure timeline with the reporter.

## Scope

Report issues in the Pyrora package, maintained examples, generated project
templates, documentation infrastructure, and the deployed store sample. Do not
send credentials, customer data, payment information, or production secrets.
